# Final Project – Computer Vision

## 1. Project Description
This project presents **PlantCare**, a deep learning–based application designed for **crop pest and plant disease classification** to support modern agricultural management. The system aims to assist farmers, agricultural practitioners, and the general public in identifying various **crop pests and plant diseases** through image-based classification of plant leaves and affected crops. In addition to providing classification results, PlantCare delivers informative outputs such as the name of the detected pest or disease, a brief description explaining its cause and characteristics, the potential impacts on plant health and crop productivity, and recommended handling or treatment methods. By leveraging deep learning and computer vision techniques, PlantCare contributes to **early detection of plant health issues**, enabling timely intervention, reducing crop loss, and supporting sustainable agriculture practices.
